# Kronos Hyper-Native Kernel (HNK) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eliminate `node.exe` from Kronos by implementing the Hyper-Native Kernel (HNK): an embedded in-process Tokio daemon, automated wire-protocol codegen, pure Rust Gitoxide (`gix`) shadow VFS, zero-copy Shared Memory Ring Buffer (SMRB), embedded Tree-sitter AST, and Tantivy in-memory workspace search.

**Architecture:** Embed an asynchronous Tokio runtime inside `kronos.exe` that serves both Windows Named Pipes (`\\.\pipe\kronos-ipc`) and local WebSocket (port 6767) with zero frontend churn. Heavy filesystem and Git operations run via pure Rust `gix` with in-memory Copy-on-Write trees, while streaming telemetry uses zero-copy circular ring buffers. A dual-engine switch (`KRONOS_DAEMON_ENGINE="rust" | "node"`) guarantees safe, zero-risk transition.

**Tech Stack:** Rust 2021, Tokio, Axum / Tokio-Tungstenite, `gix` (Gitoxide), `tree-sitter`, `tantivy`, `serde`, `serde_json`, Windows Named Pipes (`windows-sys`), TypeScript, Tauri v2.

**Spec:** `docs/superpowers/specs/2026-10-29-kronos-hyper-native-kernel-design.md`

## Global Constraints

- No `: any` or `as any` across all modified TypeScript code (`ts-no-any`).
- Retain Industrial Brutalism aesthetic standards (CRT substrate `#0A0A0A`, hazard red `#FF2A2A`, `rounded-none`).
- Windows graphics safeguards retained: `--disable-gpu-watchdog` and `.shadow(false)` in `main.rs`.
- Child process supervision must enforce `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE` via `process_job.rs`.
- All Git operations must preserve user `.gitconfig` and SSH credentials.

```rust
use serde::{Deserialize, Serialize};
use serde_json::Value;

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct RpcEnvelope {
    pub id: String,
    #[serde(rename = "type")]
    pub msg_type: String,
    #[serde(default)]
    pub payload: Value,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RpcResponse {
    pub id: String,
    #[serde(rename = "type")]
    pub msg_type: String,
    pub success: bool,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub data: Option<Value>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub error: Option<String>,
}

pub type RpcPayload = Value;
```

```rust
        let (mut ws_stream, _) = connect_async(url).await.expect("Failed to connect");

        let msg = serde_json::json!({
            "id": "ping-1",
            "type": "ping",
            "payload": {}
        });

        let response = ws_stream.next().await.unwrap().unwrap();
        let parsed: serde_json::Value = serde_json::from_str(&response.to_text().unwrap()).unwrap();
        assert_eq!(parsed["id"], "ping-1");
        assert_eq!(parsed["type"], "pong");
        daemon.stop().await;
    }
}
```
